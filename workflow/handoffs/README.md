# Handoffs

Session-continuation docs. State at a stopping point — done, in-progress, next step, open questions, key files — so the next session resumes cold without re-deriving context. Used anytime, any stage.

One file per checkpoint: `YYYY-MM-DD-handoff.md` (suffix `-HHMM` if same-day). Never overwrite — history is the point.

Written by the `handoff` skill.

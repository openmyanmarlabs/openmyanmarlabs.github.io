# Spec — Open Myanmar Content v1 (2026-05-26)

One-line: free, offline, bilingual (Burmese + English) desktop app that helps Myanmar SMEs generate social-media captions and branded image posters with local AI.
Source: `workflow/ideas/open-myanmar-content/idea.md`

## Goal

Ship a standalone macOS + Windows desktop app (Electrobun + Bun) that lets a non-technical Myanmar SME owner:

1. Generate natural Burmese + English Facebook/Instagram captions from a short brief, using local Ollama text models.
2. Render brand-styled image posters (PNG) from 20+ bilingual templates auto-filled with that caption.
3. Optionally generate decorative background images locally via stable-diffusion.cpp.

All offline, zero cost, no accounts.

## Users / context

- **Primary:** Burmese SME owner / 1–3 person marketing team (tea shop, clothing, restaurant, salon, retail). Posts FB/IG 3–5×/week. Non-technical. Burmese-first.
- **Hardware:** modern Mac (Apple Silicon) or mid-range Windows PC. May have 4GB or 8GB+ RAM.
- **Environment:** unreliable internet acceptable; only required when actually posting to FB/IG (manual paste).
- **UI defaults to Burmese (`my`)**, EN toggle in settings.

## Scope

**In (v1):**

- **Foundation:** clone `apps/electrobun-template` into `apps/open-myanmar-content`; completely remove the `auth` feature (login, register, services, validations, pages, DB tables, RPC routes, store wiring); rename app id, package name, bundle id, window title, icon paths; keep template's i18n, home shell, update banner, layout, UI components, Drizzle setup.
- **Text AI (Ollama sidecar):**
  - Bundle platform-specific Ollama binary in installer (mac arm64 + win x64).
  - First-launch model picker with RAM detection: ≥8GB → suggest Qwen2.5:7b, <8GB → suggest Gemma3:4b. User can download both, switch in settings.
  - Spawn Ollama as background sidecar (starts with app, stops with app). All calls to `localhost:11434`.
  - "Generate caption" brief form: `topic` (textarea), `tone` (Casual / Professional / Festive), `platform` (Facebook / Instagram). Output: Burmese caption, English caption, hashtag suggestions (Myanmar-relevant). User edits inline, copies per-block.
- **Templates:**
  - **SME templates:** Product Sale, New Product Launch, Flash Sale, Event Announcement, Grand Opening / Anniversary, Customer Review, Delivery / Service Update, Custom (free-form).
  - **Myanmar traditional event templates:** one per Myanmar month (12 total) per idea §2 table, each pre-loaded with festival context for the AI prompt.
  - **Custom templates:** user creates, names, saves, edits, deletes. Stored locally (SQLite). Reusable across briefs.
- **Image library:**
  - Import images from local device (drag-drop + file picker).
  - Stored as file refs in SQLite (files copied to app data dir, mirrors invoice-app precedent).
  - Browse, tag, reuse across multiple posts.
  - Basic crop + resize to platform aspect ratios: 1:1 (IG), 4:3 + 16:9 (FB).
- **AI image generation (stable-diffusion.cpp sidecar):**
  - Bundle platform-specific SD binary (mac Metal, win CUDA + CPU fallback).
  - First-launch optional download of SD 1.5 GGUF q4 (~2GB).
  - Text-to-image: user enters prompt in Burmese OR English.
  - If Burmese detected → silently route prompt through Ollama (Qwen2.5 preferred, else Gemma3) for translation; show translated EN prompt to user for review/edit before generating.
  - Subprocess call: prompt in → PNG out. Saved into image library.
  - Used for backgrounds / decorative art only. Not product photography.
- **Brand design system:**
  - One brand profile per install (v1): logo (PNG/SVG upload), primary color, secondary color, preferred font (system + bundled Burmese fonts).
  - Edit anytime in settings.
- **Poster templates (20+):**
  - 20+ bilingual templates per idea §5: promotion, new product, flash sale, event, holiday greetings (Thingyan, Tazaungdaing, Thadingyut, etc.).
  - Auto-apply current brand identity (logo, colors, font).
  - Auto-fill generated Burmese + English caption text.
  - Render PNG via Electrobun native-rasterize (HTML/CSS → WebView → PNG), same pipeline as `apps/open-myanmar-invoice`.
  - Export at correct platform dimensions (1:1 IG, 4:3 / 16:9 FB).
- **Post history:**
  - Every generated post saved to local SQLite: timestamp, platform, template used, Burmese caption, English caption, hashtags, attached/generated image ref, poster PNG ref.
  - Browse, search, filter (by template / date / platform), reuse, delete.
- **Manual mode (no model installed):**
  - User can pick template, write captions manually, save to history, organize images, render brand posters with manually-typed text.
  - AI-generate buttons disabled with inline hint: "Download model to enable".
- **Bilingual UI throughout** (Burmese + English) — default `my`, settings toggle.
- **Update banner** (inherited from template).

**Out (non-goals — v2+):**

- Login, register, accounts, cloud sync, multi-device.
- Meta API one-click publish (copy-paste only in v1).
- Multi-brand support — exactly one brand profile per install.
- Multiple social accounts per platform.
- Video, audio, reels, stories tooling.
- Team collaboration, sharing, comments.
- AI photo enhancement of imported product photos.
- Built-in FB/IG scheduling (use platform-native scheduling).
- Linux build.
- In-app analytics / post performance tracking.
- Agency multi-client features.

## Requirements

### Foundation

- [ ] `apps/open-myanmar-content` is a copy of `apps/electrobun-template` with: auth feature fully removed (no references in routes, stores, RPC, repos, migrations, i18n keys); app metadata renamed; `electrobun.config.ts` updated (app id, name, bundleId, icon); landing-site `versions.json` entry added.
- [ ] `bun test` passes; app launches; home renders without auth references.

### Text AI

- [ ] Ollama binaries (mac arm64, win x64) bundled in installer (platform-specific assets).
- [ ] App spawns Ollama as a child process on startup, kills on app quit, restarts on crash.
- [ ] First-launch screen detects RAM via OS API; suggests model accordingly; shows download progress; saves choice.
- [ ] Settings page lists installed models; user can download Qwen2.5:7b, Gemma3:4b, delete either, switch active model.
- [ ] Caption generation: brief → both-language captions + ≥5 hashtags in <30s on M3/M4 with Qwen, <60s with Gemma.
- [ ] Generated output is editable inline; per-block copy button (Burmese caption / English caption / hashtags).

### Templates

- [ ] 8 SME templates seeded.
- [ ] 12 Myanmar-month festival templates seeded with festival-aware system prompt.
- [ ] User can create custom template: name, default tone, default platform, prompt scaffold; persisted to SQLite.
- [ ] Custom templates listed alongside built-ins; user can edit, duplicate, delete (built-ins read-only).

### Image library + crop

- [ ] Drag-drop and file-picker import; files copied to app data dir; metadata (filename, dimensions, tags, source) in SQLite.
- [ ] Browse grid with thumbnails.
- [ ] Crop UI supports 1:1, 4:3, 16:9 presets and free-form; output saved as new image entry.

### SD image gen

- [ ] stable-diffusion.cpp binaries bundled (mac Metal, win CUDA + CPU fallback).
- [ ] SD model download UI on first SD use (not first launch — opt-in).
- [ ] Language detection on prompt input; if Burmese → call Ollama translate → show EN prompt; if no text model installed, show error: "install a text model to translate Burmese prompts".
- [ ] Generation completes <10s on M3/M4 Metal; <60s Windows CPU fallback.
- [ ] Output PNG auto-added to image library, tagged `ai-generated`.

### Brand + posters

- [ ] Brand profile setup wizard on first launch (skippable; can complete later in settings).
- [ ] Logo upload (PNG/SVG ≤2MB); color pickers (hex); font dropdown including bundled Pyidaungsu + Padauk.
- [ ] 20+ poster templates seeded; each renders with current brand identity automatically.
- [ ] Caption text auto-fills into poster preview; user can edit poster text independently of source caption.
- [ ] Native-rasterize export to PNG at chosen aspect ratio; "Save As…" + "Save to image library" both available.

### Post history

- [ ] Every successful generate (text or text+poster) writes a history row.
- [ ] History page: list with thumbnail, date, platform, template; search by caption text; filter by platform / template / date range.
- [ ] Open historic post → reuse (loads brief back into generator) or duplicate.
- [ ] Delete with confirm.

### Storage

- [ ] All persistent data uses Drizzle + SQLite in app data dir.
- [ ] Schema includes: `brand_profile`, `templates` (built-in + custom flag), `images`, `posts`, `settings` (active model, UI language, etc.).
- [ ] Files (images, posters, AI models, logos) stored as paths on disk; only refs in DB.

### i18n

- [ ] Every user-visible string has `en` + `my` translations.
- [ ] Default UI = `my`; toggle in settings persists.

## Constraints

- **Runtime:** Bun + Electrobun (monorepo conventions); React + Vite + Tailwind v4; Drizzle + better-sqlite3; @remixicon/react.
- **Platforms (v1):** macOS Apple Silicon AND Windows x64, shipped together. No Linux.
- **Cost:** free, open source. Zero API keys, zero subscription, zero cloud calls (except user-initiated FB/IG paste).
- **Network:** offline-capable for all features after model downloads complete. Only internet usage: model downloads + Ollama package manager + (eventually) user pasting into FB/IG.
- **Installer size:** ~150–200MB (binaries only; models pulled on first launch).
- **Local AI:**
  - Ollama sidecar @ `localhost:11434` (auto-spawned, lifecycle-managed).
  - stable-diffusion.cpp subprocess (per-generation invocation).
  - No Python anywhere.
- **Rasterize:** poster export uses Electrobun native-rasterize (mirrors invoice app).
- **Single brand profile** — schema may anticipate multi-brand but UI exposes only one.
- **Burmese language quality** matters more than English polish — Qwen2.5 is the quality default; Gemma3 is the fallback.
- **Code-signing + notarization:** both macOS (Developer ID + notarytool) and Windows (Authenticode) required for v1 release.
- **No telemetry** in v1.

## Acceptance — done when

- Clean install on a fresh M3 Mac and a fresh Windows 11 PC: app launches, asks for brand profile + text model, downloads chosen model, user enters a brief, gets bilingual caption in <30s, applies it to a festival poster template, exports PNG, opens FB, pastes caption, attaches PNG.
- Repeating the flow without the SD model installed succeeds for text + poster paths; SD-only paths show clear "download SD model" prompt.
- Quitting the app stops Ollama (no orphan process on either OS).
- Re-launching shows last brand, last active model, full post history, custom templates.
- `bun test` is green; spec-required UI flows pass manual GUI verify (mirroring [[open-myanmar-invoice-port]] verification practice).
- Both platform installers signed + notarized + uploaded to landing-site release dir; `versions.json` updated; in-app update banner can see the version.

## Open questions

- **Festival prompt content:** who authors the 12 monthly festival prompt scaffolds (tone, key phrases, sample CTAs)? Source from a Burmese marketer or draft from public references? Flag for plan time.
- **Bundled Burmese fonts:** Pyidaungsu + Padauk licensing — confirm both are OFL/redistributable for app bundling, or pick alternates. Verify before bundling.
- **20+ poster templates design:** are template visual designs already drafted somewhere, or does v1 include the design work? If design work, who provides mockups? Major schedule risk if unanswered.
- **Update banner content URL:** which landing-site path serves `versions.json` for `open-myanmar-content` (mirrors other apps but needs creation).
- **Ollama model registry:** does Ollama official registry serve Qwen2.5:7b + Gemma3:4b stably in Myanmar networks, or do we mirror? Test from MM IP before release.
- **stable-diffusion.cpp Windows CUDA fallback:** how does the app detect CUDA availability and fall back to CPU cleanly without crashing? Needs prototype.
- **AI safety / content filtering:** any minimal guardrails on text generation (politically sensitive topics in Myanmar context)? Idea is silent; flag explicitly for legal/ethical sanity check before release.
- **Telemetry stance:** confirmed none in v1 — but do we want an anonymous crash-only report path? Trivial to defer.

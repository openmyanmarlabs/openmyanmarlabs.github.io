# Workflow

Docs by stage. Flow: `ideas` → `specs` → `plans` → implementation. `learning` = reference, anytime.

- **ideas/** — idea validation docs.
- **specs/** — specifications. Leads to plans; comes before plan stage.
- **plans/** — pre-implementation docs: code-snippets, implementation states, detailed impl docs.
- **learning/** — notes from online, external resources, or feedback.
- **handoffs/** — session-continuation docs. Checkpoint + resume; anytime.

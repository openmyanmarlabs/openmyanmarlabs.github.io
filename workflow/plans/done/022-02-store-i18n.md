# 022-02 — Sidebar store + i18n nav labels

Plan: `022-root-electrobun-template-layout-shell.md` · Blocked by: — · Parallel-safe with: 01

## Goal

Create `sidebar-store.ts` (collapse state, localStorage-persisted) and extend `content.ts` with the nav labels the sidebar and AppBar need.

## Context

**Sidebar store pattern** (from invoice app `apps/open-myanmar-invoice/src/stores/sidebar-store.ts`):

- Zustand store; state: `collapsed: boolean`
- Two pure localStorage helpers for testability: `readCollapsed()` / `writeCollapsed(value)`
- `typeof localStorage !== "undefined"` guard (SSR/test-safe)
- Actions: `toggle()`, `setCollapsed(value: boolean)`
- Initialises `collapsed` from `readCollapsed()` on import

**i18n pattern** (template `apps/electrobun-template/src/lib/i18n/content.ts`):

- `my` object is the source of truth; `en` is typed `as Content` to enforce key symmetry
- Read the file before extending — the `nav` section may already have some keys (`toHome`, `toAbout`); only add what's missing
- New keys needed in `nav`: `appTitle`, `toHome`, `toAbout`, `collapseSidebar`, `expandSidebar`, `logout` — add any that are absent; do not duplicate

**TDD** — this phase uses test-first development for the store. Follow `.claude/skills/tdd/SKILL.md`. The store is pure state logic with no Electrobun runtime dependency — test it with plain `bun test`. Template currently has no store test files; this creates the first one.
